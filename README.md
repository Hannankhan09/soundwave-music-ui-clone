# Soundwave — Music Streaming UI Clone

A responsive music-streaming dashboard concept inspired by common music player layouts. Built with **HTML5, CSS3, and vanilla JavaScript** for an internship front-end task.

## Features
- Responsive desktop, tablet, and mobile layout
- Sidebar navigation, collection cards, playlists, album/mix cards, and trending tracks
- Interactive demo player controls: play/pause state, next/previous, progress scrubber, shuffle, repeat, like, and volume UI
- Create-playlist dialog that adds a playlist to the sidebar
- Toast notifications for user feedback
- Custom CSS album artwork, gradients, and hover states
- Semantic markup, accessible labels, keyboard focus states, and reduced-motion support

## Tech stack
- HTML5
- CSS3 (Grid, Flexbox, media queries, CSS variables)
- Vanilla JavaScript (DOM manipulation and event listeners)
- Google Fonts and Unsplash images for visual assets

## Run locally
Open `index.html` in a browser. Internet access is needed for the remote font and image assets. The player is a UI prototype and does not stream audio.

## Project note
This is an educational UI concept, not the official Spotify product. It uses original branding and does not connect to Spotify accounts, APIs, or paid services.
